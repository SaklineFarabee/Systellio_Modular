## Sytellio CRM

Sytellio is a comprehensive Customer Relationship Management (CRM) solution developed for Peer Solution. It is designed to streamline sales, marketing, and task management for IT startup companies.

## Features

•
Role-Based Access Control (RBAC): Secure access for Super Admins, Admins, Managers, and Agents.

•
Contact & Company Management: Track clients, companies, and their associated contacts.

•
Deal Pipeline: Manage sales opportunities through various stages.

•
Task Management: Assign and track tasks and subtasks for team members.

•
Campaign Management: Plan and monitor marketing campaigns.

•
Analytics & Reporting: Gain insights into business performance.

•
Unified Notification System: Stay updated with real-time alerts.

## Technology Stack

•
Frontend: HTML5, CSS3 (Inter font), JavaScript, Font Awesome.

•
Backend: PHP.

•
Database: MySQL/MariaDB.

## Getting Started

## Prerequisites

•
Web server (e.g., Apache, Nginx) with PHP support.

•
MySQL/MariaDB database server.

## Installation

## 1.Clone the repository:

Bash


git clone https://github.com/SaklineFarabee/sytellio-crm.git





## 2.Configure the database:

•
Update config.php with your database credentials.



## 3.Initialize the database:

•
Run the setup_db.php script or import demo_crm.sql manually.



## 4.Access the application:

•
Navigate to the project directory in your web browser.



## Security Note

This project is currently in the MVP stage. An initial authentication review has been conducted (auth_review.md ), and several critical security improvements are planned for future releases, including securing the "Remember Me" functionality and implementing prepared statements.

## Development Pipeline

•
Staging Branch: All new features and refinements are first pushed to the staging branch for review.

•
Main Branch: Production-ready code is merged into the main branch.
